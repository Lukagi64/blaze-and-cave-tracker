# Blaze & Cave's Advancements Tracker - CLAUDE.md

## Project Overview

This is a personal project to track Minecraft advancements from the **BlazeandCave's Advancements Pack** datapack. It consists of:
- **Python scripts** to extract advancement data from the datapack JSON files into SQL
- **Node.js/Express web app** with SQLite to display and track player progress
- **Future**: Minecraft plugin (currently empty folder)

## Development Workflow

### Regenerating the advancement seed data

When the datapack is updated (new version or modifications):

```bash
cd "Script Python"
python extract_advancement.py
```

This reads all JSON files in `BlazeandCave's Advancements Pack 1.21.1/data/blazeandcave/advancement/` and generates `Site web/db/seed_advancements.sql`.

### Running the web app locally

```bash
cd "Site web"
npm install        # First time only
npm start          # Runs on http://localhost:3000
```

### Running with Docker

```bash
cd "Site web"
docker-compose up -d
```

### Database location

- Development: `Site web/data/database.sqlite` (auto-created on first run)
- Docker: `/app/data/database.sqlite` (mounted from `./data`)

## Important Implementation Details

### Advancement extraction logic (`extract_advancement.py`)

- **Input**: Datapack JSON files at `./BlazeandCave's Advancements Pack 1.21.1/data/blazeandcave/advancement/`
- **Output**: `Site web/db/seed_advancements.sql` with INSERT statements
- **Key mapping**: 
  - `technical_key` = `blazeandcave:<category>/<name>` (e.g., `blazeandcave:nether/into_the_fire`)
  - `category` = first subfolder name (nether, mining, adventure, etc.)
  - `difficulty` = derived from `display.frame`: task→vert, goal→bleu, challenge→violet, super challenge→rouge, milestone→jaune, secret→rose
- **Skips**: root.json (tab icon), advancements without `display` block

### Database schema (`Site web/db/schema.sql`)

- **Joueur**: uuid (PK), pseudo, twitch_channel, created_at
- **Advancement**: technical_key (PK), name, category, difficulty (CHECK: vert/bleu/violet/rouge/jaune/rose)
- **Progression**: player_uuid + advancement_key (composite PK), completed_at, FKs with CASCADE
- **Indexes**: On category, difficulty, completed_at DESC, player_uuid

### Environment variables (`Site web/.env`)

Required:
- `PORT` (default 3000)
- `DB_PATH` (default `./data/database.sqlite`)
- `API_SECRET_TOKEN` - for authenticating progress submissions
- `TWITCH_CLIENT_ID` / `TWITCH_CLIENT_SECRET` - for Twitch integration

## Common Tasks

### Adding a new advancement category

1. Add JSON files to the datapack folder under `data/blazeandcave/advancement/<new_category>/`
2. Run `python extract_advancement.py`
3. Verify `seed_advancements.sql` has new entries
4. Commit both datapack changes and seed file

### Updating the datapack version

1. Replace contents of `Script Python/BlazeandCave's Advancements Pack 1.21.1/` with new version
2. Run extraction script
3. Check for any schema changes needed (new difficulty values, etc.)
4. Commit all changes

### Debugging the web app

```bash
cd "Site web"
# Check database directly
sqlite3 data/database.sqlite ".tables"
sqlite3 data/database.sqlite "SELECT * FROM Advancement LIMIT 5;"

# View server logs
npm start
```

## Troubleshooting

| Issue | Solution |
|-------|----------|
| `better-sqlite3` build fails | `cd "Site web" && npm rebuild better-sqlite3` |
| Python script finds no files | Check `DATAPACK_ADVANCEMENTS_DIR` path in `extract_advancement.py` |
| Docker permission denied | Run Docker Desktop, or `sudo` on Linux |
| Port 3000 in use | Change `PORT` in `.env` or kill process on 3000 |
